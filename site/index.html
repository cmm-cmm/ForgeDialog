Dialogs that behave themselves.

A dependency-free TypeScript dialog library built on the native <dialog> element. Accessible by default, themeable down to individual components, and small enough that an alert-only bundle stays under 6 KB gzipped.

npm install forgedialog

What you get

Everything below is in the published package — no plugins to install, no peer dependencies to satisfy.

Accessible by default

Focus is trapped and restored, Escape and backdrop clicks are wired up, and ARIA roles are set for you. Focus detection skips targets that only look focusable.

Styled per component

Colour and opacity for the surface, title, body, and border. Corner radius per corner. Shadows composed from an angle, distance, blur, and strength.

Hover, drag, and gestures

Opt-in hover restyling with lift and scale. Draggable dialogs with axis locks, bounds, keyboard movement, and persisted positions. Swipe-to-dismiss sheets.

More than alerts

Drawers, bottom sheets, lightboxes, loading states, toasts, a command palette, and persisted branching wizards — all from the same core.

Honest bundles

Tree-shakable entry points with enforced gzip budgets. Import forgedialog/alert and you pay for an alert, not the whole library.

Fits your stack

ESM, CJS, and a browser global, with adapters for React, Vue, Svelte, and Web Components. Typed throughout, SSR-safe, and clean under a strict CSP.

Playground

Change anything below and the dialog restyles live. The code updates with it — copy it and you have the same dialog in your app.

Examples

The everyday calls. Each returns a promise, so there is no callback nesting.

Replace the browser built-ins

import { alert, confirm, prompt } from 'forgedialog';
import 'forgedialog/style.css';

await alert('Saved successfully.', { title: 'Success' });

const ok = await confirm('Delete this item?');

const name = await prompt('What is your name?', {
  validate: (value) => value.trim() ? true : 'Name is required',
});

Build your own dialog

import { open } from 'forgedialog';

const dialog = open({
  title: 'Custom dialog',
  content: (container) => container.append(renderForm()),
  buttons: [
    { text: 'Cancel', onClick: (i) => i.close(null) },
    { text: 'Save', role: 'primary', onClick: (i) => i.close(read()) },
  ],
});

const result = await dialog.whenClosed();

Pay only for what you use

// Just an alert, and nothing else.
import { alert } from 'forgedialog/alert';
import 'forgedialog/style/core.css';

// Opt into the richer appearance options on a focused entry.
import 'forgedialog/appearance';
